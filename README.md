# 💬 ChatSphere – Real-Time Chat Application

ChatSphere is a full-stack real-time chat application that enables users to communicate instantly through a modern and interactive interface. The application is built using React.js, Node.js, Express.js, Socket.IO, and MongoDB.

## 🚀 Features

- ✅ Real-time messaging using Socket.IO
- ✅ Online users tracking
- ✅ Typing indicator
- ✅ Emoji support
- ✅ Image sharing
- ✅ Dark/Light mode
- ✅ Chat history storage with MongoDB
- ✅ Responsive and user-friendly interface
- ✅ Username-based chat participation
- ✅ Auto-scroll to latest messages
